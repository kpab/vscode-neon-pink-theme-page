## 🌃 About

This is the official landing page for [Neon Pink Dark](https://github.com/kpab/vscode-neon-pink-theme), a cyberpunk-inspired dark theme for Visual Studio Code.

**Live Site:** [https://kpab.github.io/vscode-neon-pink-theme-page/](https://kpab.github.io/vscode-neon-pink-theme-page/)

## 🌐 Internationalization

The landing page supports English and Japanese with a simple toggle system:

- Language preference is saved in `localStorage`
- All text content uses `data-en` and `data-ja` attributes
- Instant switching without page reload
- Auto-detection of browser language (coming soon)

## 🔧 Development

### Local Development

1. Clone the repository:
```bash
git clone https://github.com/kpab/vscode-neon-pink-theme-page.git
cd vscode-neon-pink-theme-page
```

2. Open with a local server:
```bash
# Using Python 3
python -m http.server 8000

# Using Node.js (with http-server)
npx http-server

# Using VS Code Live Server extension
# Right-click index.html > "Open with Live Server"
```

3. Visit `http://localhost:8000` in your browser

### GitHub Pages Deployment

This site is automatically deployed to GitHub Pages from the main branch.

**Deployment URL:** `https://kpab.github.io/vscode-neon-pink-theme-page/`

To deploy updates:
```bash
git add .
git commit -m "Update landing page"
git push origin main
```

Changes will be live within a few minutes.
