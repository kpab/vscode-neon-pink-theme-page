Installation

From VS Code Marketplace

  1. Open Extensions view (Ctrl+Shift+X or Cmd+Shift+X)
  2. Search for "Neon Pink Dark"
  3. Click Install
  4. Select theme (Ctrl+K Ctrl+T or Cmd+K Cmd+T)

From Command Line

code --install-extension kpab.neon-pink-dark
